This list covers tools ranging from clinical assessment diagrams for social work to modern AI-powered ancestry visualization.

## Modern Genogram Builders
*Next-generation tools focusing on AI, automation, and user experience.*

* **[GenogramAI](https://genogramai.com)** - AI-powered genogram creation tool that automates family mapping for therapists and professionals.
* [Canva Genograms](https://www.canva.com/graphs/genograms/) - Simple, drag-and-drop templates for creating basic visual genograms.
* [Creately](https://creately.com/diagram/genogram-software/) - Collaborative diagramming tool with specific templates for family systems.
* [Lucidchart](https://www.lucidchart.com) - Professional diagramming software widely used for mapping family relationships.

## Professional & Clinical Tools
*Heavy-duty software used by social workers, family therapists, and medical geneticists.*

* [GenoPro](https://www.genopro.com) - The legacy standard for creating complex family trees and genograms (Windows).
* [Progeny Genetics](https://www.progenygenetics.com) - Clinical pedigree drawing software used primarily in healthcare and genetic counseling.
* [Standard Genogram](https://www.standardgenogram.com) - Specializes in standardized symbols for family therapy assessments.
* [SmartDraw](https://www.smartdraw.com/genogram/) - Enterprise-grade diagramming with automated formatting.

## Developer Libraries & APIs
*Open source libraries for rendering family trees and graphs in your own applications.*

* [GoJS Genogram](https://gojs.net/latest/samples/genogram.html) - A JavaScript diagramming library with powerful interactive genogram samples.
* [d3-dag](https://github.com/erikbrinkman/d3-dag) - Layout algorithms for visualizing directed acyclic graphs (DAGs) and family trees.
* [React Family Tree](https://github.com/bbum/react-family-tree) - A React component for rendering family tree hierarchies.
* [FamilySearch API](https://www.familysearch.org/developers/) - Extensive API for accessing the world's largest collection of genealogical data.

## Genealogy & DNA Platforms
*Consumer platforms for ancestry research and DNA analysis.*

* [Ancestry](https://www.ancestry.com) - The largest genealogy company in the world.
* [MyHeritage](https://www.myheritage.com) - Global discovery platform for family history and DNA testing.
* [GEDmatch](https://www.gedmatch.com) - Tools for DNA and genealogical analysis.
* [Gramps](https://gramps-project.org) - A free software project and community for genealogy research.
